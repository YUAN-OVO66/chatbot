# 天气查询技能

## 流程

1. 确认用户要查询的城市
2. 调用脚本查询实时天气和未来 3 天预报
3. 根据天气情况给出穿衣或出行建议（如果用户问了的话）

## 可用脚本

- `scripts/get_weather.py` — 查询城市实时天气 + 3 天预报
  - 执行方式: `python C:/tmp/skills/weather/scripts/get_weather.py <城市名>`
  - 参数: 城市名（中文，如"北京"、"上海"、"杭州"）
  - 返回: 实时天气（天气状况、温度、体感温度、湿度、风向风速、气压、能见度）+ 未来 3 天预报

## 注意事项

- 如果用户未指定城市，默认查询北京
- 使用 shell 工具执行脚本，使用绝对路径
- 脚本依赖 `QWEATHER_API_KEY` 环境变量（和风天气免费版 API Key）
- 如果 API Key 未配置，脚本会报错提示
