# 文本摘要助手技能

## 流程

1. 获取用户提供的文本内容
2. 分析文本结构和关键信息
3. 生成不同长度的摘要

## 可用脚本

- `scripts/text_analyzer.py` — 文本分析工具
  - 执行方式: `python C:/tmp/skills/summary/scripts/text_analyzer.py "文本内容"`
  - 功能: 字数统计、段落分析、关键词提取、可读性评估

## 注意事项

- 使用 shell 工具执行脚本，使用绝对路径
- 摘要应保留原文核心观点
- 根据用户需求生成不同长度的摘要（一句话/一段/详细）
- 对技术文档保留关键术语和数据
